## Approach
Keep literal replay for legacy steps. For newly verified SCROLL→pagination CLICK programs, derive an optional `until_role` only when a safe strictly grounded target moves from wholly below the CSS viewport to wholly inside it in a verified scroll, with unchanged URL/site/results and identity. Replay that scroll conditionally: skip it if its target is inside the viewport, repeat while it remains below and distance decreases, refuse unknown/changed geometry, and preserve all action/time/progress limits. Geometry is not clickability: every actual click and whole program must still verify.

Alternatives considered: unconditional runtime rewriting would reinterpret old contradictory fixtures and legacy memories; a general loop language is unnecessary scope. This narrow typed prerequisite preserves both. This is an authored execution/compiler improvement, not proof of autonomous learning.
