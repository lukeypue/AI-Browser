## App test seam
Use variant-specific com.appgate.tv.serverlab.ServerLabRuntime (debug/release counterparts). Main service delegates profile selection; release returns the unchanged default filter. Debug observer is active only with serverAndroidLab=true plus installed instrumentation listener. DiagnosticsLog emits its existing strict PhoneReportExporter result to that debug-local observer inside its serial snapshot, before clearing context; release observer is always absent. Sharing remains OFF. No exported production component or dangerous permission is added. Debug app uses applicationIdSuffix .serverlab; no release field/signing edits. Test runner is a custom android.app.Instrumentation subclass (no new instrumentation dependencies required).

Runner commands smoke/cycle/probe write only validated typed JSON in files/serverlab/<cycle UUID>.json or files/serverlab/probe.json, retrievable only with fixed adb serial emulator-5580 and run-as com.aibrowser.universal.serverlab. A complete cycle requires actual elapsed>=1800000ms, end reason DEADLINE, interruption false, engine readiness, verified actions and retained learning. Teacher transport is OFF for synthetic runtime reliability tests. Expose no raw logs/preferences/cookies/page text/URLs/screenshots.

A memory projection includes only hashes of procedural bodies and structural bindings, failed procedure hashes and verified lesson IDs (not timestamps, query values or raw IDs/text). Its fingerprint must match after clean app stop/new process and emulator cold restart. Capture after the engine executor is quiescent. An interrupted in-flight cycle is reported INTERRUPTED, never completed; restart begins a new full deadline with prior memory.
