# Site Brain 7.2.13

The learning dashboard now has **TEST 30 MIN** and **TEST 60 MIN**. A test practices
across eligible sites with the current local/AI settings, then stops and saves a
privacy-safe summary. Pauses count toward the deadline. Opening the browser to
teach ends the test; normal overnight learning retains its existing browser handoff.
A service restart marks the test interrupted rather than restarting it silently.

Use **SHARE TEST DIAGNOSTICS** after the run, or save diagnostics to Downloads.
The summary separates verified actions, failed actions, completed attempts and
verified procedure uses. Repeated successful practice is not counted as new lessons.
Task logs already include planner calls, outcomes, typed failure coordinates and
reported teacher token usage. Phone logs remain local until explicitly shared.

Fixed a retry-history bug: the old thirty-second expiration erased repeated failures
on every site retry. Two failures now hold the unchanged procedure shape for six
hours. Different procedures, changed relevant controls or verified success can
recover sooner. The ordinary site retry schedule remains thirty seconds.

Automated JVM coverage checks both deadlines, pause-inclusive elapsed time, outcome
accounting, idempotent finalization and bounded duration. Regression coverage now
checks retained failures across repeated site retries and eventual expiry. The
signed Android pipeline validates app compilation, unit tests, fixtures and release
publication. Live phone behavior still requires the user's timed test and diagnostics.

An hourly repository review was scheduled to react to new test failures or supplied
sanitized diagnostics. It cannot fetch unshared phone logs, remotely install updates,
or guarantee unattended access to the Gemini/Claude/Copilot browser sessions.
